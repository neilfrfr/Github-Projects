🌤️ WeatherNow

A modern, responsive, and beginner-friendly weather dashboard built with Python and Streamlit. It fetches real-time data and forecasts using the completely free Open-Meteo APIs.

Features

Location Search: Easily search for cities worldwide.

Current Conditions: View temperature, "feels like", humidity, wind speed, and precipitation.

7-Day Forecast: Daily high/low temperatures and conditions.

Hourly Forecast: A visual chart showing temperature trends for the next 24 hours.

Unit Toggle: Instantly switch between Celsius and Fahrenheit.

Robust Error Handling: Gracefully handles invalid inputs, API timeouts, and network issues.

Tech Stack

Python 3.11+

Streamlit (Web UI framework)

Requests (API communication)

Open-Meteo APIs (Weather and Geocoding - No API key required!)

Pandas (Data manipulation for charts)
